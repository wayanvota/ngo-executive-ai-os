# Memory Folder

This folder is the assistant's persistent memory. It is designed for Obsidian and for Codex-style folder-based work.

Memory should be useful, sparse, and source-aware.

## Core Files

- `executive-profile.md`: executive priorities and preferences
- `judgment-rules.md`: durable decision rules
- `fundraising-pipeline.md`: active fundraising work
- `commitments.md`: promises and follow-up

## Folders

- `donors/`: donor and prospect profiles
- `board/`: board member and governance context
- `partners/`: strategic partners and coalitions
- `projects/`: strategic projects and grant-funded work
- `private/`: sensitive notes excluded from git

## Memory Quality Rules

- Keep one durable fact per line when practical.
- Add source links or source notes.
- Mark unverified items as `Unverified`.
- Delete stale assumptions.
- Do not store beneficiary-sensitive detail unless required and approved.
