# Donor Profiles

Create one markdown file per donor, foundation, funder, or major prospect.

Use `templates/donor-profile.md`.

Good donor memory includes:

- last meaningful contact
- relationship owner
- current ask or renewal status
- stated interests
- restrictions
- open commitments
- source links or source notes
- likely objection
- next best action

Do not store sensitive personal inferences or unsupported claims about donor motivation.
