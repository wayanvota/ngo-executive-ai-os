# Security

This repository is a prompt and memory starter kit. It is not a secure CRM, grant-management platform, or compliance system.

## Sensitive Data

Do not commit:

- donor private information
- beneficiary stories with identifying details
- HR or legal records
- grant agreements not cleared for sharing
- board minutes
- financial records
- credentials, tokens, or API keys

The `memory/private/` folder is ignored by git, but local ignore rules are not a substitute for judgment.

## Responsible Use

Use this kit first with synthetic or sanitized data. Move to real organizational context only after your organization has approved the data handling rules.

Keep these actions human-approved:

- donor communication
- board communication
- grant submissions
- public statements
- financial claims
- impact claims
- account connections
