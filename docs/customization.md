# Customization Guide

The default kit is generic. Make it useful by narrowing it to the executive, the organization, and the fundraising model.

## First Customizations

Edit these files first:

1. `memory/executive-profile.md`
2. `memory/judgment-rules.md`
3. `memory/fundraising-pipeline.md`
4. `memory/commitments.md`

Then create donor profiles using `templates/donor-profile.md`.

## Choose Your Fundraising Model

Most small NGOs rely on a mix of:

- institutional grants
- major donors
- foundations
- corporate partnerships
- individual giving
- board-sourced introductions
- earned revenue or contracts

The assistant should track the model you actually use. Delete sections that do not apply.

## Define Priority Rules

Add rules such as:

- Renewal deadlines outrank new prospects.
- Board-requested follow-up must be visible within 48 hours.
- Restricted grants require program and finance review before any donor-facing draft.
- No impact claim leaves the organization without a source.
- Never imply causality when the evidence only supports contribution.

## Keep It Small

The assistant becomes useful when memory is accurate, not when it is large.

Start with:

- top 10 donors
- top 5 prospects
- active proposals
- board commitments
- current strategic goals

Add more only after the weekly review is working.
