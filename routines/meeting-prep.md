# Meeting Prep Routine

## Purpose

Prepare the executive for a donor, board, funder, partner, or internal strategy meeting.

## Inputs To Review

1. relevant person or organization profile from `memory/`
2. `memory/commitments.md`
3. `memory/fundraising-pipeline.md`
4. relevant project files
5. agenda or source documents from the user

Ask before using connected private accounts.

## Output

Produce:

1. `Meeting Objective`: what should be true after the meeting.
2. `Context`: what the executive needs to know.
3. `Relationship State`: trust, history, sensitivities, and unresolved commitments.
4. `Likely Interests`: only source-backed or clearly labeled as inference.
5. `Key Questions To Ask`: questions that improve strategy or fundraising.
6. `Recommended Ask Or Decision`: the strongest reasonable ask.
7. `Do Not Say`: claims, framings, or topics that create risk.
8. `Follow-up Draft`: optional draft language for review, never sent automatically.

## Rules

- Use source-backed context when possible.
- Mark unsupported assumptions.
- Make the recommended ask specific.
- Do not over-script the executive.
