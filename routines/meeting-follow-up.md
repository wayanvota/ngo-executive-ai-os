# Meeting Follow-up Routine

## Purpose

Turn a meeting note, transcript, or rough recap into decisions, commitments, follow-up drafts, and memory updates.

## Inputs To Review

1. meeting note, transcript, or user recap
2. relevant profile files in `memory/`
3. `memory/commitments.md`
4. `memory/fundraising-pipeline.md`

## Output

Produce:

1. `Decisions Made`
2. `Commitments Made By Us`
3. `Commitments Made By Others`
4. `Follow-up Needed`
5. `Draft Message For Review`
6. `Fundraising Pipeline Updates`
7. `Memory Updates To Apply`
8. `Open Questions`

## Rules

- Separate decisions from discussion.
- Separate commitments from possibilities.
- Do not mark a task complete unless the user says it is complete.
- Do not edit memory unless asked.
- Drafts must remain approval-gated.
